# 毕业论文撰写大纲：校园二手物品交易平台的设计与实现

> 本大纲与项目代码一一对应，写作时可直接结合 `sql/schema.sql`、`backend/src`、`frontend/src` 中的实现展开。
> 建议篇幅：本科论文 2.5~3.5 万字；每章按"是什么 → 为什么 → 怎么做 → 效果/截图"展开。

## 第一章 绪论

### 1.1 研究背景与意义
- 高校二手物品（教材、数码、生活用品）浪费与闲置问题；跳蚤市场、QQ 群交易的安全与效率痛点
- 本系统意义：校园实名制场景下，提供审核把关 + 实时议价 + 订单保障的二手交易闭环

### 1.2 国内外研究现状
- 国外：eBay、Poshmark 等 C2C 模式
- 国内：闲鱼、转转 与高校闲置平台对比；指出校园场景特殊性（实名、线下见面、审核需求）

### 1.3 主要研究内容
- 前后端分离架构；多角色权限；物品发布与审核；聊天议价；订单状态机；数据可视化

### 1.4 论文组织结构
- 各章内容一句话概述

## 第二章 相关技术介绍

- **Spring Boot**：起步依赖、自动装配、内嵌 Tomcat
- **MyBatis-Plus**：BaseMapper 通用 CRUD、分页插件、字段自动填充、Lambda 条件构造器
- **MySQL 8**：表设计、索引、事务（订单状态流转一致性）
- **JWT + 拦截器**：无状态认证原理（Header/Playload/Signature），前后端分离下的鉴权方案
- **Vue 3 + Vite + Element Plus + Pinia + Vue Router**：Composition API、响应式、路由守卫、状态管理
- **WebSocket**：与 HTTP 轮询对比，实时消息推送原理
- **ECharts**：数据可视化
- **Thumbnailator**：图片缩放压缩
- 每节配技术选型理由（为什么选它，对比其他方案）

## 第四章 系统设计

### 4.1 总体架构设计
- 前后端分离架构图：浏览器(Vue SPA) → Nginx/Vite代理 → Spring Boot REST API → MySQL；WebSocket 实时通道
- 后端分层：Controller → Service → Mapper（MyBatis-Plus）→ MySQL
- 统一响应结构 `Result{code,message,data}`、全局异常处理、JWT 拦截器鉴权流程

### 4.2 功能模块设计
- 认证模块、用户模块、分类模块、物品模块（含审核状态机）、聊天模块、订单模块（含状态机）、统计模块、管理模块
- 建议为每个模块配一张功能结构图或时序图
- 关键状态机：
  - 物品状态：0待审核 → 1在售 → 2已下架 / 3已售出；0待审核 → 4已驳回
  - 订单状态：0待付款 → 1待发货 → 2待收货 → 3已完成；0/1 → 4已取消

### 4.3 数据库设计
- **ER 图**（建议用 PowerDesigner/Draw.io 画）：6 张表及关系
- **表结构设计**（与 `sql/schema.sql` 对应，逐表列出字段、类型、约束、注释）：
  1. `user` 用户表（角色、状态）
  2. `category` 分类表（两级：parent_id）
  3. `item` 物品表（status、sensitive_hit、view_count、images 逗号分隔）
  4. `chat_message` 聊天表（is_read、item_id 议价上下文）
  5. `orders` 订单表（状态机字段、各时间戳）
  6. `sensitive_word` 敏感词表
- 设计说明：为什么字段这么设计；索引设计（user_id、status、buyer_id/seller_id 等）；外键取舍（逻辑外键）

### 4.4 接口设计
- RESTful 风格约定；统一返回格式；分页参数规范；鉴权 Header（`Authorization: Bearer <token>`）
- 按模块列出主要接口（可引用 README 第八节并补充请求/响应示例 JSON）

## 第五章 系统实现

> 每小节：实现思路 + 核心代码片段（截取关键方法）+ 界面截图 + 效果说明

### 5.1 认证与权限管理实现
- BCrypt 加密、JWT 签发/解析（`JwtUtil`）、`JwtInterceptor` 拦截 `/api/**` 与 `/api/admin/**` 角色校验
- 前端路由守卫 + Axios 拦截器携带 token、401 自动跳转

### 5.2 物品发布与图片压缩实现
- `ImageUtil`：Thumbnailator 等比缩放 + 质量压缩，GIF 原样保存
- 前端 `ImageUpload` 组件：多图上传、预览、删除、压缩提示

### 5.3 违规内容审核实现
- DFA 字典树算法原理（构建与匹配过程，附代码 `SensitiveWordUtil`）
- 发布时自动扫描（`sensitive_hit` 标记）→ 管理员审核队列（`Audit.vue`）→ 通过/驳回
- 敏感词词典管理 + 在线检测；聊天消息同样过滤

### 5.4 分类检索实现
- 两级分类树接口与级联选择器；后端 LambdaQueryWrapper 动态条件（关键字/分类含子类/价格区间/排序）

### 5.5 私信议价实现
- WebSocket 握手鉴权（token 参数）、在线会话管理、`ChatService.send` 推送新消息
- 前端聊天页：会话列表 + 消息窗口 + 未读角标 + 断线轮询兜底
- 议价与订单联动：下单弹窗支持填写议价后成交价

### 5.6 订单全流程实现
- 状态机校验（非法流转拦截）、订单号生成、支付/发货/收货/取消各操作与物品状态联动（支付锁定物品、取消恢复在售）
- 买家/卖家双视角订单列表与操作按钮

### 5.7 交易数据可视化实现
- 统计 SQL（`OrderMapper` 聚合查询：趋势、分类、排行、状态分布、用户增长）
- ECharts 图表：折线/饼图/柱状图 + 核心指标卡片 + 自适应 resize

### 5.8 管理端实现
- 布局、审核、用户、物品、订单、分类、敏感词七个页面；`/api/admin/**` 权限保护
